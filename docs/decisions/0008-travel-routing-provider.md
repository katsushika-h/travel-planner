# ADR 0008: Travel routing provider

**Status:** Proposed (2026-10-16).

**Context:** Phase 1 of travel distance shows straight-line walking estimates between consecutive stops (`lib/travel-legs.ts`, haversine distance with a detour factor). These are poor for real street routes and useless for driving. The app has no Google billing (`AGENTS.md`), is single-user with no authentication, and cannot use the public OSRM demo server, which is not permitted for application use. The map already uses OpenStreetMap, so an OSM-based router fits the existing data and attribution.

**Decision:** Use hosted OpenRouteService (ORS) with the profiles `foot-walking` and `driving-car`, called only from a server route (`POST /api/route-legs`) through `lib/ors-client.ts`, which posts `{"coordinates": [[lng, lat], [lng, lat]]}` (longitude first) to `https://api.openrouteservice.org/v2/directions/{profile}` and reads `routes[0].summary` (`distance` in metres, `duration` in seconds) and `routes[0].geometry` (encoded polyline). The key is the server-only env var `ORS_API_KEY`, sent in the `Authorization` header and never sent to the browser or logged. Routed legs are cached in a new Prisma model `RouteLeg`, unique on profile plus origin and destination coordinates rounded to 5 decimals (about 1 m), and treated as stale after 90 days. The browser falls back to the phase 1 straight-line estimate when the key is missing, the quota is hit, or ORS fails. ORS attribution is shown next to the OSM attribution whenever routed legs are shown. Travel mode (walk or drive) is a per-trip UI preference in `store/use-travel-store.ts`; there is no `Trip` schema change. Fallbacks if ORS stops fitting: self-host ORS (same API, different base URL), or Valhalla if public transit is needed (hosted ORS has no transit); Overpass for parking if ORS POIs are insufficient (phase 3).

**Consequences:** Stop coordinates are sent to HeiGIT, the ORS operator. The free-plan quotas (checked 2026-10-15: directions 2,000/day and 40/min, matrix 500/day, POIs 500/day) are ample for a single user once legs are cached, but they can change and should be re-checked before relying on them. The free plan is non-commercial, so commercial use would need a paid plan or self-hosting. The new migration means the migrator image must be rebuilt at deployment. Travel mode and any leg overrides live in the browser store, so they do not sync across devices; syncing would need a `Trip` field later.
