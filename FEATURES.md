# Feature ideas

Potential features to implement after the POC. These are ideas, not commitments or a prioritized roadmap.

- [ ] **Attach travel documents** — attach flight tickets, hotel reservations, and other files to trips or itinerary items.
- [ ] **Export locations to Google My Maps** — export itinerary locations as an importable CSV or KML file.
- [ ] **Import a Google Maps saved list** — import a Google Takeout export, preview its places, and create one itinerary item per place for a selected trip and day. Preserve each place's notes, tags, and Maps URL where available.
- [ ] **Unscheduled items** — keep itinerary ideas without a date until they are ready to be scheduled.
- [ ] **Undo** — allow recently made changes to be reversed.
